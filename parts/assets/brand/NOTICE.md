## Files

All four are single-colour SVG drawings in millimetres, fills only (no text, images, CSS or strokes), derived from the Neural Deep Network Ltd website illustration: a woman's head with circuit-board hair and a hexagonal emblem.

| File | What it is |
|------|------------|
| `neuraldeep-mark-2x4.svg` | The portrait mark (line-art face, circuit-trace hair, cube-in-hexagon crown) drawn for a 2x4 tile; the default artwork of `parts/ndn.brand-tile.obpart.json`. |
| `neuraldeep-mark-4x6.svg` | The same portrait mark redrawn for a 4x6 tile, with outer hair traces. |
| `neuraldeep-badge-4x4.svg` | The hexagon badge with the same face, drawn for a 4x4 tile; the default artwork of `parts/ndn.brand-badge.obpart.json`. |
| `neuraldeep-badge-2x2.svg` | The hexagon badge drawn for a 2x2 tile. |

The part documents that name these files (`ndn.brand-tile`, `ndn.brand-badge`) are CC0 like the other parts; the artwork they use by default is not. The sample mark `parts/assets/mark.svg` (CC0) stays the default of `parts/ndn.logo-tile.obpart.json`.
