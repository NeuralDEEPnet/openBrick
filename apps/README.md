# Apps

`web/`: the browser app. It already has the M1 browser pipeline: the Rust core as WebAssembly in a Web Worker and a three.js viewer (see [web/README.md](web/README.md)). It grows into the playground and, in M4, the PWA. `desktop/` (from M2): the Tauri 2 project that also builds Android (M4) and iOS (M5). See docs/plan/09.
