# Bundled fonts

Only SIL Open Font License 1.1 fonts, shipped as complete, unmodified files with their copyright and licence text (subsetting would trigger Reserved Font Name rules). Candidates, each to be checked for Reserved Font Names before bundling: Liberation Sans (default; OpenSCAD users know it), Inter, Noto Sans, Atkinson Hyperlegible, plus a CJK-capable Noto face for localisation. Each weight carries `printSafe` metadata (minimum stroke at 10 mm cap height) in `fonts/index.json` once added in M4. Generated 3D text carries no font-licence obligation (OFL FAQ).
