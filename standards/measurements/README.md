# Measurement program (CC0)

Raw caliper, micrometer and CMM measurements of reference parts go here as CSV, one file per session: `YYYY-MM-DD-<who>-<instrument>.csv` with columns `part,sample,feature,value_mm,instrument,temperature_c,notes`.

Reference set (20 to 30 samples each): 2x4 brick, 1x2 plate, 1x2 Technic brick, 2L pin (friction and frictionless), 3L axle, 1x1 clip, towball, click-hinge brick. The open rows of the Dimensional Standard (pin shaft, axle arm, counterbore, hole axis height, hinge fingers, ball sockets) are resolved from these files. See docs/plan/04 section 8.
